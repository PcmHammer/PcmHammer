# PCM Labels

Reference photos of PCM labels / boards, filed by **service number**, used to confirm
which OSIDs belong to which PCM type (the label prints the type and the service number).

## Naming

    <PcmType>_<ServiceNumber>_<view>.png

where `<view>` describes the shot: `label` (the ID label), `top` (connector side),
`board` (PCB), etc. e.g. `E92_12674052_label.png`, `E92_12674052_top.png`.
