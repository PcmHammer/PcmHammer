Read This First

This software was written by a few people in their free time. While it has worked well for us, we can't promise the reliability and trustworthiness that you would expect from a commercial product. If you require foolproof, commercial-quality tools, this software is not for you.

For several seconds after you turn the key, the PCM is busy booting, and most operations will fail during that period. This is why the app asks you to wait before proceeding with complex operations. If you skip that waiting period you won't do any lasting damage, but whatever you are trying to do might not work, and you might need to pull the PCM's fuse for a few seconds to reset it.

Many of the app's operations transfer custom software (a "kernel") to the PCM. While that software is running, normal PCM functions are suspended, so you will see and hear a variety of error messages and chimes. This is normal. When the app is done, the PCM reboots and works normally again.

If you have a drive-by-wire throttle, you might find that the Check Engine light turns on after a read or write, and a code reader will report P1518, indicating a communication error with the Throttle Actuator Control module. This can be ignored; it will clear after you start the engine a few times. We are looking for a way to prevent it.

Supported Devices

This app currently supports the following types of devices.

OBDX Pro - recommended

The best bang for the buck. It supports 4x bus speeds and large data packets, which makes it both fast and reliable. Full disclosure: the people behind this company have also helped with PCM Hammer development and testing, and buying through this link helps cover our hardware costs and fund future development.

ObdLink Scantool SX - works, but slow; not recommended

An inexpensive, basic interface. It is better than ELM knock-off devices, but it does not support 4x (high-speed) mode and only handles relatively short messages, so it is very slow - a full read of a 512 KB PCM takes a little over 20 minutes. Wired only (no Bluetooth).

ObdLink Scantool MX / MX+ - not recommended

Similar to the SX, but with Bluetooth. The Bluetooth connection to Windows can be troublesome, but it does work once it is correctly configured.

ObdLink Scantool LX - not recommended

Like an SX or MX+, but wireless.

Scanmatik version 2 (firmware 2.21.23+ and version 3) - supported

Scanmatik added official long-packet support with firmware 2.21.23, after being contacted by PCM Hammer users in 2023. Reports are that this tool works well at 4x, via J2534.

GM or Bosch MDI and MDI2 tools - supported

These are supported J2534 devices with the needed protocol support. They are not cheap, but they are strong performers. Tech2 with J2534 passthrough should work, but is not tested.

AVT 852 - supported

An expensive option. The original company has closed down, but the device is being manufactured again by Mobilechanix, who have a website and an eBay store. This was one of the first interfaces to properly support J1850 VPW high-speed mode.

Other J2534-compatible interfaces - work in theory, but often don't

Any J2534 interface that supports J1850 VPW and large packets should work, at least in theory. There are quite a few on the market and we cannot test them all, but if you have one, give it a try; over time we will list the ones that are proven to work. The genuine GM MDI is one device that is known to work well. Cheaper J2534 devices are generally very basic and either skip the VPW protocol or cannot handle large packets - as a general rule, sub-$50 J2534 tools usually do not work.

Note that the Tactrix OpenPort 2.0 does not support J1850 VPW, despite some advertising that says it does. VPW is required, and the OpenPort cannot provide it.

ObdDiag AllPro - no longer available; not recommended

Only the USB and dev-board versions are supported (not Bluetooth). The AllPro devices were quite inexpensive, and ObdDiag was an early partner in this project, incorporating changes and responding to feedback. However, the person behind the company has moved on to other things, so these devices are no longer available. If you happen to have one, it can be used, but they are uncommon. Note that AllPro devices purchased before early June 2018 need a firmware update to version 1.21 or later.

Other STN-based devices - not recomended

Other devices based on the Scantool STN OBD2 chip may or may not work, depending on their message-size limits - the same caveats apply as for the ScanTool products above.

ELM-based devices - not supported

ELM-based devices are not supported, because they cannot handle large packets. Reading and clearing OBD2 trouble codes is one thing; rewriting firmware is quite another.

Supported PCMs

This version of PCM Hammer supports the following PCMs:

P01, P04 (all variants), P05, P05b, P08, P10, P11, P12, P12b, P59, E54, and the 98/99 Vortec Black Box.

This is most of the VPW-protocol GM PCMs, from around 1996 to 2007.

PCM Hammer does not currently support writing the slave CPU. Some of the PCMs above have a second, dedicated CPU for electronic throttle control. If you try to change the operating system on one of these PCMs, PCM Hammer will warn you, because doing so can break electronic throttle support. After such a change you would need to reflash the slave CPU for the new operating system using Techline or other flash software, or reflash back to the original operating system with this software to restore the original function. For these PCMs it is best to change only calibration items when working with this tool.

Note that this software does not support CAN-protocol PCMs, such as the E38 and newer, which started appearing around 2005.

Different PCMs support different types of write in PCM Hammer. The app will tell you if you attempt an operation that is not supported, and how to work around it.

Basic Operations

Turn the ignition key to the "On" position. (The "Acc" position will not work.) The dashboard should light up. Do not start the engine.

Select Device

Before the app can communicate with your PCM, you need to tell it what kind of interface you have and how it is connected to your computer.

  1. Click the "Select Device" button on the main window. A dialog box will appear.
  2. Select "Serial Port Device" or "J2534 Device", depending on which type you have. If you don't know which, it is probably a serial port.
  3. For a serial device, select the COM port and device type from the drop-down lists. For a J2534 device, select the device type.
  4. Use the Test button to check that you got it right, or just click OK.
  5. Either way, check the Results tab in the main window: it will either print an error message or show some information about the selected device.

Identify PCM

Reads the VIN, serial number, and other identification from the PCM. You should generally do this before anything else, to confirm that the device can communicate with the PCM.

Test Write

Simulates the process of updating your PCM's calibration block from a file on your computer, without changing the contents of your PCM. This is useful for verifying the quality of the connection between your computer and your PCM.

Write Calibration

Erases and reprograms the calibration section of your PCM's flash memory - the tuning, basically. It can take several minutes, and if it is interrupted your PCM may be left unusable, so make sure your car battery and laptop battery are fully charged. Once the process begins, don't do anything that might interrupt it: don't close the app, reboot the computer, spill coffee on the keyboard, and so on.

Halt Kernel

You will probably never need this. But if you interrupt a read or quick-compare operation by closing the app, you can use it to halt the PCM Hammer kernel and reboot the PCM. If a write operation is interrupted, do not use this button. Instead, just start another write - the app will detect that the kernel is already running and restart the write.

Some additional operations are available in the Tools menu:

Read Entire PCM

Saves the entire contents of the PCM's read-only memory to a new file of your choice. You can open the resulting file in TunerPro if you have the definition file (the "XDF") that corresponds to your PCM's operating system.

Verify Entire PCM

Checks whether a file on your computer matches the contents of the PCM. This takes a minute or so, but it is quicker than reading the entire PCM and then comparing the two files on your computer.

Change VIN

Click the button, enter your vehicle's VIN, and click OK. The change does not take effect until after you turn off the ignition: the PCM keeps running on battery power for a few seconds while it stores the new VIN permanently. If you disconnect all power before then, the PCM will still have the original VIN the next time you turn it on.

You may find this useful if you have bought a used PCM from a junkyard or online retailer - for example, after bricking your own PCM with amateur software downloaded from the internet. (Although, honestly, zero PCMs have been harmed during the development of this app. So far.)

Write Parameters

Erases and reprograms the parameter sections of your PCM's flash memory. These sections contain the VIN, serial number, stored OBD2 codes, and so on. This is useful when you are replacing an old PCM with one from another vehicle.

Write OS, Calibration, and Boot

Erases and reprograms everything except the parameter sections. This is useful when you want to update the operating system in your vehicle.

Write Full Flash (Clone)

Erases and reprograms the entire contents of the PCM's flash memory. To the best of our knowledge, this makes the target PCM indistinguishable from the original.

Related Resources

TunerPro
After using PCM Hammer to read the contents of your PCM, you will want to edit your new ".bin" file. TunerPro is the recommended tool for that job.
Alternatively, look into Universal Patcher. It can identify tuneable items in a generic way.
XDF Files
TunerPro is a generic editing tool: it does not know anything about your PCM or your .bin file. It needs a definition file to tell it which bytes of the .bin file control which aspects of the PCM. PCM Hammer reports the operating system ID (OSID) of your PCM once you are set up and click "Identify PCM". You can search for that OSID together with "XDF" to see what is available online. You will need to judge which XDFs are of good quality; the better ones usually come recommended online, or appear in PCMHacking.net posts with lots of downloads and positive comments in the thread. Sometimes it is best to change the operating system to a more common, compatible OSID so that you can get extra features or a better XDF.
LogViewer
After using PCM Logger to read data from your PCM, you will want to view the contents of your new ".csv" file. There are many tools for this. LogViewer is the simplest possible option - click here to download it.
